# Seishun Wallpapers Pack

A high-quality wallpaper collection based entirely on *Rascal Does Not Dream of Bunny Girl Senpai*.

This pack includes aesthetic desktop wallpapers inspired by the anime, featuring Mai Sakurajima and iconic moments from the series.

---

## Preview

* High-resolution wallpapers
* Anime aesthetic visuals
* Clean and dark themed wallpapers
* Perfect for desktop setups

---

## Installation

1. Go to the **Releases** section of this repository.
2. Download the latest `.zip` file.
3. Extract the files anywhere on your PC.
4. Set your favorite wallpaper.

---
